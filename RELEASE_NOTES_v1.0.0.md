# TMT Chow v1.0.0

First stable release of the TMT Chow Home Assistant integration.

## Highlights

- Open, close and stop the gate from Home Assistant
- Live gate status and position
- Battery monitoring
- Read and change supported ChowHUB controller parameters
- Home Assistant UI setup
- Diagnostics
- 23 supported languages

## Languages

Bulgarian, Croatian, Czech, Danish, Dutch, English, Finnish, French, German, Greek, Hungarian, Italian, Norwegian Bokmål, Polish, Portuguese, Romanian, Russian, Slovak, Slovenian, Spanish, Swedish, Turkish and Ukrainian.

## Notes

This is an unofficial community integration and is not an official TMT Automation product.
